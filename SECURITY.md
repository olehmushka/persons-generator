# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for a security vulnerability.

Instead, use GitHub's private vulnerability reporting: go to the
[Security tab](https://github.com/olehmushka/persons-generator/security/advisories/new)
and open a new draft security advisory. This reaches the maintainer directly
without disclosing the issue publicly.

## Scope

This is a personal, single-maintainer project — there's no formal SLA on
response time, but reports are taken seriously and will be looked at as soon
as possible. If a report turns out to be a real vulnerability, a fix will be
released and the advisory published (with credit, if you'd like it) once a
patch is available.

## Supported Versions

Only the latest release/`main` is supported. There's no long-term maintenance
of older versions.
